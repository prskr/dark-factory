# Tasks

## 1. Spikes (before implementation)

- [ ] 1.1 Native sidecars under Kata: on a cluster with a Kata `RuntimeClass`, run a pod with one init container `restartPolicy: Always` (TCP startup probe) and the agent container. Record: the agent starts after the probe passed; the pod ends when the agent ends; the status and kubelet events for an image pull failure, for a first termination (`restartCount`, `CrashLoopBackOff`) and for a startup-probe kill (`lastState.terminated` reason and exit code, `Unhealthy`/`Killing` events with `involvedObject.fieldPath`). Repeat the probe-kill case on runc (kind). Write the results into design D2 and D4; if Kata fails, add the startup refusal of the Risks section to the tasks.
- [ ] 1.2 Playwright MCP in the restricted pod: run `mcr.microsoft.com/playwright/mcp` (pinned digest) as user 1000, `allowPrivilegeEscalation: false`, no capabilities, with `--headless --no-sandbox --port 8931 --output-dir /tmp/shared` and `--proxy-server=$(HTTPS_PROXY)`. Check: the startup probe passes; Claude Code reaches `http://localhost:8931/mcp` over Streamable HTTP; a screenshot lands in `/tmp/shared`; an allowed external site loads through the gateway; `localhost` bypasses the proxy; `/dev/shm` is not a problem. Write the final example (image, args, ports, resources) into design D6 and D9.
- [ ] 1.3 PostgreSQL in the restricted pod: run `postgres` (pinned digest) as user 1000 with `fsGroup` 1000, an `emptyDir` at `/var/lib/postgresql/data` and `PGDATA=/var/lib/postgresql/data/pgdata`. Check that `initdb` succeeds and the agent container connects at `localhost:5432`. Write the working example into design Goals and the how-to draft.
- [ ] 1.4 Local listeners: in a run pod of each harness (`claude-code`, `opencode`), list listening TCP sockets (`ss -ltnp` or `/proc/net/tcp*`). Record the result in design D10. If a harness listens without authentication, stop and ask Peter Kurfer before enabling sidecars for that harness.
- [ ] 1.5 HTTP MCP support of the harnesses: check that the Claude adapter and `opencode acp` advertise `mcpCapabilities.http`, accept an HTTP server in `session/new` and `session/load`, and reach a sidecar at `localhost` with the pod's proxy variables set (with the new `NO_PROXY`). Check that the `agent-client-protocol` crate version has `McpServer::Http`. Record in design D5.
- [ ] 1.6 Landlock across the mount: with an `emptyDir` at `/tmp/shared`, check that the harness under Landlock can read and write it and that `write_artifact` with a path below it succeeds.
